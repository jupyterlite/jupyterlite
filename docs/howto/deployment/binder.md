# Deploying on Binder with `jupyter-server-proxy`

A JupyterLite site can be deployed behind `jupyter-server-proxy` using any
[local server](../../quickstart/standalone.md) method. This is a good way to
interactively preview the deployment of e.g. a Lab extension that can work in both the
"full" binder experience, and as a static preview.

```{hint}
See the JupyterLite [binder configuration] for an example.
```

[binder configuration]: https://github.com/jupyterlite/jupyterlite/tree/main/.binder
